# omarchy dotfiles

  Personal dotfiles and configuration for my personal/work workstation, running Omarchy 4 (Quattro).

  ## What's inside

  - `hypr/` - Hyprland config (Lua), copied from `~/.config/hypr/`
    - `bindings.lua` - ALT-based binds (launchers, HJKL focus, workspaces, ALT+D push-to-talk dictation), with conflicting SUPER defaults unbound
    - `monitors.lua` - laptop + two 1080p externals
    - `looknfeel.lua` - no gaps, borders, blur, or animations
    - `input.lua` - keyboard repeat, compose on caps, touchpad scroll
    - `hyprsunset.conf`, `xdph.conf` - night light and screen-share portal
  - `omarchy/shell.json` - Omarchy shell bar layout and idle timers (copied from `~/.config/omarchy/`)
  - `mimeapps.list` - default apps (Firefox as browser)
  - `git/config` - Git config

  Pre-Quattro configs (Hyprland `.conf`, waybar, swayosd) live in the git history before the Quattro upgrade commit.
